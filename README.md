# 🏝️ 무럭무럭 그림 마을

그리고, 세고, 나누며 나만의 마을을 키우는 **4~7세 교육 게임**.
아이가 그린 도형이 그대로 캐릭터가 되어 마을에 살아갑니다.

**▶ 플레이: https://sangheelim123.github.io/grim-village/**
(폰에서 열고 "홈 화면에 추가"하면 앱처럼 설치되고 오프라인에서도 동작합니다)

## 놀이

| 섬 | 놀이 | 발달 영역 |
|---|---|---|
| 🌉 길 그리기 | 선을 그어 친구를 집에 데려다주기 | 전서기 획 (직선→대각선→곡선→각→소용돌이) |
| 🥚 도형 알 | 도형을 그리면 그 그림이 캐릭터로 부화 (십자·엑스 등 다획 도형, 레벨 5 기억 그리기) | 도형 인지, 소근육, 시각 기억 |
| 🍎 냠냠 | 과일을 세어 친구에게 먹이기 (먹인 만큼 성장), 레벨 3+ 덧셈(모아 담기)·뺄셈(나눠 주기) | 수 세기, 일대일 대응, 덧셈·뺄셈 |
| 💠 반짝 | 별사탕을 색·모양 바구니에 분류 | 분류, 규칙 전환 |
| 🎨 그림 놀이터 | 자유 그림 → 캐릭터 부화 | 창의 표현 |
| 🐠 수족관 | 그린 물고기가 색 그대로 헤엄침, 먹이 주기·쓰다듬기 | 창의 표현, 돌봄 놀이 |

- 캐릭터의 도형·이름·성격을 전부 아이가 선택, 도감에서 짝꿍 지정·그림 리플레이
- 적응형 난이도(4세~7세), 형제 프로필 2개, 한국어 음성 안내
- 실패 없음 · 별은 아무것도 잠그지 않음 · 방치 페널티 없음

## 기술

Phaser 3 · 자작 벡터 아트 48종 · 사전 렌더링 합성 사운드 · PWA (오프라인)

```bash
# 로컬 실행
python3 -m http.server 8000   # → http://localhost:8000

# 단일 파일 배포본 (dist/무럭무럭그림마을.html)
node tools/build-standalone.mjs
```
